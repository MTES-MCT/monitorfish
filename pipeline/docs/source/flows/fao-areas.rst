=========
FAO areas
=========

The ``FAO areas`` flow extracts FAO areas from the `FAO geoserver <https://www.fao.org/fishery/geoserver/fifao/ows>`__ (WFS) 
and loads it to the ``fao_areas`` table of the Monitorfish database.

It is run manually when necessary, in order to sync the Monitorfish database with the FAO data after an update.
