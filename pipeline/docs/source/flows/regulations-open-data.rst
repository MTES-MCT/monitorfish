=====================
Regulations open data
=====================

The ``Regulations open data`` flow publishes the :doc:`regulated fishing areas <../regulation>` of the ``regulations`` table :

* as a CSV file and a GeoPackage file on the `data.gouv.fr dataset <https://www.data.gouv.fr/datasets/reglementation-des-peches-cartographiee/>`__
* on the `Géoplateforme <https://www.geoportail.gouv.fr>`__ of the IGN, where it is made available as a geographic data service

It is scheduled to run every Friday.
